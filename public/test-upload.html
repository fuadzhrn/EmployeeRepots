🧪 File Upload Diagnostics

Configuration Check:

  • Form method: POST
  • Form enctype: multipart/form-data
  • Max file size: 2MB
  • Allowed extensions: pdf, doc, docx, xls, xlsx, jpg, jpeg, png, txt, zip
  • Storage path: /storage/app/public/documents/

Browser Console Tips:

  1. Open your browser's Developer Tools (F12 or Ctrl+Shift+I)
  2. Go to the "Console" tab
  3. You'll see debug messages when:
    • File is selected
    • File size is checked
    • File type is validated
    • Form is submitted

Test File Upload:

Go to Home Page and:

  1. Fill in all form fields:
    • Request Name: any text
    • Badge No: any number
    • Category: select one
    • Description: at least 10 characters
  2. Select or drag a file:
    • Should be less than 2MB
    • Supported format (pdf, txt, jpg, etc.)
  3. Click "Submit Request"
  4. Watch browser console for debug messages
  5. Check if success/error message appears

❌ If Upload Failed:

Please provide these details:

  1. Screenshot of browser console errors (F12 > Console tab)
  2. The error message shown on the page
  3. File name and size you tried to upload
  4. File format/type

✅ If Upload Succeeded:

You should see:

  1. Green success message with checkmark animation
  2. Form automatically reset after 2 seconds
  3. Ability to upload another file
  4. File appears in admin panel
